# Grab & Grow website

Official static website for Grab & Grow: Food Catch.

- Home: https://mindslinks.github.io/
- Support: https://mindslinks.github.io/support/
- Privacy: https://mindslinks.github.io/privacy/

GitHub Pages serves the main branch at / (root). Keep .nojekyll. No Node build or client JavaScript is required. Preview with `python3 -m http.server 8766`.

The October 2026 refresh uses the approved current app icon and real English gameplay captures from the current game source. Images are resized for web delivery; no gameplay was generated. Gameplay artwork belongs to the game. Support and privacy content reflects local saves, private iCloud progress, optional notifications and App Store update checks.

The earlier exported Next.js assets are retained for recoverability; current pages load only assets/site.css and the four current assets images.
